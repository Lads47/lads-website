# Triage labels

Les skills utilisent les cinq rôles canoniques suivants. Les noms de labels restent identiques dans GitHub Issues de `Lads47/lads-website`.

| Rôle canonique | Label GitHub | Usage |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Ticket à qualifier par l'agent chargé du suivi. |
| `needs-info` | `needs-info` | Information indispensable absente après recherche. |
| `ready-for-agent` | `ready-for-agent` | Travail suffisamment spécifié pour une exécution autonome. |
| `ready-for-human` | `ready-for-human` | Intervention humaine indispensable, avec motif explicite. |
| `wontfix` | `wontfix` | Demande écartée avec justification. |

Employer ces labels lorsqu'un skill mentionne le rôle correspondant. Conserver les labels thématiques existants. Réévaluer le triage quand de nouvelles informations arrivent ; vérifier les dépendances avant de démarrer un ticket prêt pour un agent.
